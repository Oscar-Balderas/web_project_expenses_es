# TripleTen web_expense_tracker

Interactive web application to manage a personal budget and track expenses by category.

It allows users to set a budget, add expenses dynamically, and visualize real-time statistics.

---

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- DOM manipulation
- Dynamic calculations

---

## 📊 Features

- Set an initial budget
- Add and remove expenses
- Automatic calculation of:
  - Total expenses
  - Average expense
  - Remaining balance
- Category-based statistics
- Identification of the highest spending category
- Dynamic updates without page reload
